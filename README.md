# Projeto 02 (Trilha Simplificada) - Card de Receita Simples

## 📌 Sobre o Projeto

Este projeto dá continuidade aos fundamentos de front-end, introduzindo o uso de imagens dentro de um layout organizado. Aqui, construímos um componente único: um **card de receita**, exibindo uma imagem no topo, seguida de um título e uma breve descrição.

O foco principal é aprender a posicionar imagens dentro de um contêiner, trabalhar com responsividade usando `width: 100%` e reforçar boas práticas de acessibilidade com o uso do atributo `alt`.

---

## 🛠️ Tecnologias e Conceitos Abordados

### **HTML5**

* Uso da tag `<img>` para exibição de imagens.
* Propriedades essenciais: `src` (caminho da imagem) e `alt` (texto alternativo).
* Importância do atributo `alt` para **acessibilidade**, **SEO** e **experiência do usuário**.

### **CSS3**

* Responsividade básica com `width: 100%` na imagem.
* Uso de `border-radius` para criar cantos arredondados.
* Aplicação de `box-shadow` para destacar o card.
* Uso de `padding` e `margin` para organização do espaço interno e externo.
